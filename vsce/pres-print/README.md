# RoomOS Macros - Printable Presentation

This is a print-friendly version of the RoomOS Macros presentation slides.

## Features

- **All slides visible** - No need to navigate, all slides are displayed on one page
- **Print-optimized** - Page breaks between slides, simplified colors, and print-friendly layout
- **No navigation** - Clean presentation without interactive controls
- **Landscape format** - Optimized for A4 landscape printing

## How to Use

### Viewing on Screen
1. Open `index.html` in your web browser
2. All slides will be displayed in order
3. Scroll through to review

### Printing
1. Open `index.html` in your web browser
2. Press `Ctrl+P` (Windows/Linux) or `Cmd+P` (Mac)
3. Select your printer settings:
   - **Orientation**: Landscape
   - **Paper size**: A4 or Letter
   - **Margins**: Default or Minimum
4. Click Print

### Exporting to PDF
1. Open `index.html` in your web browser
2. Press `Ctrl+P` (Windows/Linux) or `Cmd+P` (Mac)
3. Select "Save as PDF" as the destination
4. Choose Landscape orientation
5. Save the PDF

## Notes

- GIF demos from slides 10-15 are hidden in print mode as they don't translate well to print
- Animations and interactive elements are disabled
- Colors are simplified for better print quality
- SVG icons are replaced with emoji icons for better compatibility

## Differences from Interactive Version

The printable version differs from `/vsce/pres/` in these ways:
- All slides are visible simultaneously
- No navigation controls or keyboard shortcuts
- No animations or transitions
- Simplified styling for print
- Page breaks between slides
- Hidden GIF demonstrations
