Video.Matrix.Assign(args)

Assigns video sources to an output to make simple video compositions.

Output: Number, required (1-2)
SourceId: Number, optional (1-5, up to 4 sources)
Layout: String, optional ('Equal', 'Prominent')
Mode: String, optional ('Add', 'Replace')
RemoteMain: Number, optional (1-4)

Reliability and Resilience

Automatic Reconnection

Handles network failures gracefully with automatic reconnection attempts. Manual relaunch available via the title bar.

🛡️

Protection Against Deletion

codec.confirmMacroDelete is enabled by default. Requires explicit confirmation before permanently deleting a macro from the device.

⚡

Automatic Restarts

Automatic restart of the framework upon macro upload, activation or deactivation (codec.autoRestartOnActivateDeactivate).

3-Step Quick Start

1

Install

Search for "RoomOS Macros" by Zacharie Gignac in the Marketplace (Ctrl+Shift+X) and click Install.

2

Connect

Click on "Add Profile" and enter the IP address of your codec and your administration credentials.

3

Code

Existing macros are displayed. Create, edit, save, and deploy instantly.
