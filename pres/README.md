# RoomOS Macros Extension Website

A beautiful, modern website showcasing the RoomOS Macros VS Code extension by Zacharie Gignac.

## 🎨 Features

- **Modern Design**: Sleek dark theme with gradient accents
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **Smooth Animations**: Fade-in effects, parallax scrolling, and interactive hover states
- **Clean Layout**: Card-based design with clear information hierarchy
- **Performance Optimized**: Minimal dependencies, pure HTML/CSS/JS

## 📁 Files

- `index.html` - Main HTML structure
- `styles.css` - Complete styling with CSS animations
- `script.js` - Interactive features and scroll animations

## 🚀 Usage

Simply open `index.html` in any modern web browser. No build process or dependencies required!

### Local Development

1. Open the folder in VS Code
2. Install the "Live Server" extension (optional)
3. Right-click `index.html` and select "Open with Live Server"

Alternatively, just double-click `index.html` to open in your default browser.

## 🔧 Customization

### Changing Colors

Edit the CSS variables in `styles.css`:

```css
:root {
    --primary: #007ACC;
    --secondary: #68217A;
    --accent: #00D4FF;
    /* ... */
}
```

### Modifying Content

Edit the HTML in `index.html` to update:
- Feature descriptions
- Section titles
- Links and CTAs

### Adjusting Animations

Modify animation timing and effects in `script.js` and `styles.css`.
